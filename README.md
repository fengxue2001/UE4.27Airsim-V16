# 基于 AirSim 与 UE4.27 的无人机作训一体化平台

基于 Unreal Engine 4.27 与 Microsoft AirSim 构建的无人机巡检与飞手训练一体化平台。
项目面向变电站等复杂场景，集成飞行训练、任务演练、飞行复盘、空间安全防护与巡检流程验证能力，支持点云地图、三维重建场景与多机型仿真。

---

## 项目简介

本项目主要用于：

* 无人机飞手训练与操作演练
* 复杂场景下的巡检任务验证
* 无人机空间安全防护研究
* 点云地图与三维场景下的体素围栏实验
* 无人机巡检任务流程联调

平台基于 UE4.27 与 AirSim 搭建，并结合 Blueprint 与 C++ 完成业务逻辑和核心安全模块开发。

# 主要功能

## 1. 无人机飞行训练系统

* 支持多地图、多机型选择
* 支持飞手训练流程控制
* 支持检查点（Checkpoint）任务
* 支持训练评分与排行榜

### 包含功能

* HUD 飞行状态显示
* 飞行计时
* 路径任务引导
* 分数统计
* 全局状态管理

---

## 2. 飞行回放系统

基于 UE4 Demo Record / Demo Play 封装实现。

### 支持功能

* 飞行过程录制
* 飞行轨迹回放
* 回放控制
* 训练复盘

用于：

* 飞手训练分析
* 安全事件复盘
* 算法验证

---

## 3. 空间安全防护系统

项目核心模块之一，基于 C++ 实现。

### 功能包括

* 点云/场景体素化
* 三维地理围栏
* 边界距离计算
* 碰撞/越界判定
* 风险等级评估
* 分级干预

### 风险等级

| 等级        | 状态    |
| --------- | ----- |
| Safe      | 正常飞行  |
| Warning   | 接近围栏  |
| Danger    | 高风险区域 |
| Emergency | 越界/急停 |

---

## 4. 动态护盾系统

基于无人机与围栏边界距离动态调整。

### 功能

* 动态材质反馈
* 风险颜色变化
* 护盾缩放
* 风险可视化

### 护盾反馈

| 风险等级 | 护盾颜色 |
| ---- | ---- |
| 安全   | 绿色   |
| 预警   | 黄色   |
| 危险   | 橙色   |
| 紧急   | 红色   |

# 点云体素围栏

项目支持基于点云地图生成三维体素围栏。

### 处理流程

```text
点云地图
   ↓
空间切块(Tile)
   ↓
点云查询
   ↓
坐标转换
   ↓
体素索引生成
   ↓
Instanced Mesh 可视化
```

### 关键技术

* Point Cloud 空间查询
* World / Actor / Component 坐标转换
* 点云局部坐标恢复
* 体素索引映射
* Instanced Static Mesh 批量渲染

# C++ 核心模块

## 1. GeoFenceVolume

基础地理围栏组件：

* 空间边界检测
* 点是否在围栏内判断
* 边界距离计算

---

## 2. VoxelGeofenceActor

体素围栏生成模块：

* 点云读取
* 点云体素化
* 体素集合管理
* 围栏可视化

---

## 3. SafetySupervisorComponent

安全监督组件：

* 实时风险检测
* 限速控制
* 急停触发
* 动态护盾更新

---

# 坐标系统处理

项目中处理了多种坐标系统：

* UE World Coordinate
* Actor Coordinate
* Component Coordinate
* PointCloud Local Coordinate

解决了：

* 点云地图与围栏错位
* 点云偏移
* Component Transform 不一致
